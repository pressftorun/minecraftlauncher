# Изменения

## Не выпущено

- Добавлена настройка CustomSkinLoader через ExtraList: скины TLauncher загружаются в игре по прямому HTTPS-адресу с приоритетом перед стандартными источниками. Основной конфиг и пользовательские настройки сохраняются; модель скина определяется автоматически, ответ проверяется как PNG.

## 0.3.7 — 2026-10-29

- Добавлен полный комплект лицензий и уведомлений зависимостей лаунчера, включая Inter, fNbt и нативные библиотеки; лицензии точной версии .NET runtime добавляются при упаковке.
- Полные уведомления включены в NOTICE.md, чтобы сохранить совместимость с уже выпущенными обновляторами; добавлена проверка их переноса и отката при ошибке обновления.

## 0.3.6 — 2026-10-28

- Исправлено обновление списка клиентских модов: отдельный архив около 9 МБ вместо скачивания всей сборки около 273 МБ.
- Добавлены прогресс и количество загруженных мегабайт. Ограничение общей длительности загрузки заменено тайм-аутом отсутствия новых данных.
- Обязательные моды больше не отображаются как опциональные и не удаляются прежними переключателями.
- Добавлены проверки медленной загрузки, обрыва соединения, неполного файла, выбора архива и переноса мода в обязательные.

## 0.3.5 — 2026-10-28

- Добавлен выбор русского и английского языка в настройках; язык сохраняется между запусками.
- Интерфейс переключается без перезапуска, включая формы входа, настройки, статусы установки, обновления и опциональных модов.
- Смена языка сохраняет введённые данные формы аккаунта.

## 0.3.4 — 2026-10-28

- Исправлена ошибка «Файл вне папки лаунчера» при обновлении из папки с завершающим разделителем в пути.
- Добавлена регрессионная проверка такого пути.
- Для перехода с 0.3.2 или 0.3.3 требуется один раз распаковать архив поверх лаунчера, сохранив `data/` и `launcher.json`; следующие обновления устанавливаются из программы.

## 0.3.3 — 2026-10-28

- Цвет текста и значка кнопки «Клиентские моды» приведён к палитре меню, включая выбор и наведение.
- Список опциональных модов читается из `optional-mods/`, названия и ID извлекаются из метаданных JAR.
- Кнопка «Обновить список» загружает актуальные опциональные моды из клиентской сборки.
- Тумблеры сохраняют выбор; перед запуском игры в `mods/` устанавливаются только включённые опциональные моды.

## 0.3.2 — 2026-10-28

- Добавлена проверка обновлений лаунчера при запуске и в настройках.
- Официальный архив Windows/Linux x64 скачивается с проверкой SHA-256; после закрытия приложения файлы заменяются и лаунчер перезапускается.
- При обновлении сохраняются пользовательские данные и настройки; при ошибке копирования восстанавливаются предыдущие файлы.
- Добавлены раздел «Клиентские моды» и папка `optional-mods/` в клиентском пакете.
- Для перехода с версии без встроенного обновления нужно один раз распаковать архив поверх старого лаунчера.

## 0.3.1 — 2026-10-21

- Клиент автоматически скачивается из последнего стабильного релиза `pressftorun/minecraftversion`. Токен GitHub не требуется.
- SHA-256 проверяется перед установкой; актуальный локальный архив используется повторно.
- «Проверить файлы» восстанавливает сгенерированные JAR NeoForge.
- Тайм-аут действует на весь процесс загрузки файла. Незавершённые загрузки не заменяют проверенный архив.
- Проверка файлов и повторный запуск заблокированы, пока работает Minecraft.
- Готовые архивы для Windows x64 и Linux x64 включают .NET и не содержат игру, Java, моды или пользовательские данные. Зависимости скачиваются при установке.

## 0.3.0 — начальная версия

- Портативный лаунчер на C# и Avalonia.
- Установка Minecraft 1.21.1, NeoForge 21.1.264 и Java 21.
- Профили по нику, Ely.by и TLauncher.org; пароли и токены не сохраняются.
- Настройки памяти и Java, скины профилей, статус сервера и BlueMap.
