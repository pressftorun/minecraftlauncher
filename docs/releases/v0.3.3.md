# Create Launcher 0.3.3

- Исправлен цвет текста и значка кнопки «Клиентские моды»: теперь они следуют палитре меню, включая выбор и наведение.
- Список модов автоматически читается из `optional-mods/`; названия и ID берутся из метаданных JAR.
- Кнопка «Обновить список» загружает актуальные опциональные моды из клиентской сборки.
- Рабочие тумблеры с сохранением выбора: перед запуском в `mods/` попадают только включённые опциональные моды.

Версию 0.3.2 можно обновить кнопкой «Обновить» в лаунчере. Настройки игры сохраняются.
