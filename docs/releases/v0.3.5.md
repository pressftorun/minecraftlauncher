# Create Launcher 0.3.5

- Добавлен выбор русского и английского языка в настройках лаунчера.
- Интерфейс переключается без перезапуска; язык сохраняется между запусками.
- Переведены формы входа, настройки, статусы установки, обновления и опциональных модов.
- Смена языка сохраняет введённые данные формы аккаунта.

Для Quick Skin обновите файлы клиента, затем включите мод в разделе «Клиентские моды».
