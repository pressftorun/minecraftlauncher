# Create Launcher 0.3.6

- «Обновить список» загружает небольшой архив опциональных модов вместо всей клиентской сборки.
- При скачивании видны прогресс и загруженные мегабайты. Медленное соединение больше не прерывается из-за общего лимита в пять минут; тайм-аут срабатывает, если минуту не поступают новые данные.
- При обрыве или неполной загрузке предыдущий проверенный архив сохраняется.
- Обязательные библиотеки нельзя отключить прежними опциональными переключателями.

После обновления лаунчера нажмите «Проверить файлы», чтобы установить обязательную Craft Config Library 1.1.12. Затем используйте «Обновить список» в разделе «Клиентские моды».
