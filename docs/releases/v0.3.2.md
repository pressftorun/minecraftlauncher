# Create Launcher 0.3.2

- Проверка обновлений лаунчера при запуске и в настройках.
- Загрузка официального архива для Windows/Linux x64 с проверкой SHA-256, замена файлов после закрытия и перезапуск.
- Сохранение пользовательских данных и настроек, восстановление предыдущих файлов при ошибке копирования.
- Раздел «Клиентские моды» и отдельная папка `optional-mods/` в пакете клиента.

Для перехода с версии без встроенного обновления распакуйте этот релиз поверх старого лаунчера один раз. Следующие версии можно устанавливать из приложения.
