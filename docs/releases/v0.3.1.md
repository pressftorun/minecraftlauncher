Портативный лаунчер для Minecraft **1.21.1** и NeoForge **21.1.264**.

### Скачать и запустить

- **Windows x64:** скачайте `CreateLauncher-0.3.1-win-x64.zip`, распакуйте весь архив в доступную для записи папку и запустите `CreateLauncher.exe`.
- **Linux x64:** скачайте `CreateLauncher-0.3.1-linux-x64.zip`, распакуйте, выполните `chmod +x CreateLauncher`, затем `./CreateLauncher`. Требуется графическая сессия и системные библиотеки X11/fontconfig/OpenGL.

.NET устанавливать не нужно. Выберите профиль и нажмите «Установить и играть». Лаунчер скачает клиент из [публичного релиза minecraftversion](https://github.com/pressftorun/minecraftversion/releases/latest), Minecraft, NeoForge и Java 21. Файлы сохраняются в `data/` рядом с лаунчером.

### Исправления

- Автоматическое получение клиентского пакета из GitHub Releases с проверкой SHA-256 и повторным использованием кэша.
- Восстановление отсутствующих сгенерированных JAR NeoForge через «Проверить файлы».
- Ограничение времени на запрос и скачивание файла, безопасная очистка незавершённой загрузки.
- Блокировка установки и повторного запуска при работающей игре.

### Обновление и проверка

Завершите игру, сохраните резервную копию своей папки `data/` и распакуйте новый лаунчер поверх старого. Затем нажмите «Проверить файлы». Для новой установки `client.zip` вручную скачивать не требуется.

`SHA256SUMS.txt` содержит контрольные суммы двух архивов. Пользовательские аккаунты, токены, миры и журналы в релиз не включены.

Сборка, встроенные тесты, скачивание клиента без токена и восстановление NeoForge проверены. На Windows выполнен реальный запуск игры. Linux собирается и проходит встроенные тесты в CI; запуск графического клиента Linux и успешный вход на игровой сервер отдельно не подтверждены.
