# Create Launcher 0.3.4

- Исправлена ошибка «Файл вне папки лаунчера» при обновлении: путь установки с завершающим разделителем теперь проверяется корректно.
- Добавлена проверка этого случая в тесты.

В версиях 0.3.2 и 0.3.3 ошибка возникает до загрузки обновления. Для перехода распакуйте 0.3.4 поверх лаунчера один раз, сохранив папку `data/` и свой `launcher.json`. Следующие обновления устанавливаются кнопкой в программе.
